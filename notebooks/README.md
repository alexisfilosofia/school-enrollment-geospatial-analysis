# Public Sanitized Notebooks

This folder contains clean public notebooks created for portfolio review.

- `01_quantitative_enrollment_analysis_sanitized.ipynb` analyzes aggregate enrollment, course and age trends using `data/sample_anonymized_enrollment.csv`.
- `02_geospatial_analysis_sanitized.ipynb` analyzes aggregate distance, category and static map outputs using the same public CSV.

These notebooks are not copies of the private working notebooks. They are reproducible public versions based on synthetic/anonymized data. They avoid personal records, row-by-row exports and private file paths.

Run them from the repository root so the sample CSV path resolves correctly.
